Architecture overview

Factory Inventory Management System

A two-tier demo app: a Vue 3 single-page app talks to a FastAPI service over JSON/HTTP. The backend loads JSON files into memory at startup. There's no database, no authentication and no persistence.

System architecture

Two local processes. The browser loads the SPA from Vite on :3000, and the SPA calls the API directly on :8001. CORS is open, and there's no Vite proxy.

Data flow: changing a filter

The main interaction. All four filters live in one shared composable and are re-sent as query params on every fetch.

  1. User picks a filter

    FilterBar.vue binds to Time Period, Warehouse, Category and Order Status.

  2. Shared state updates

    useFilters.js keeps module-level refs, so every view sees the same values. getCurrentFilters() maps selectedLocation → warehouse and selectedPeriod → month.

  3. View refetches

    Views call methods on api.js, which drops any value equal to 'all' and builds a URLSearchParams string.

  4. FastAPI filters in memory

    apply_filters() does exact or case-insensitive matching on warehouse, category and status. filter_by_month() substring-matches order_date and expands Q1-2025…Q4-2025 via QUARTER_MAP.

  5. Validated & returned

    A Pydantic response_model shapes the JSON. Aggregate endpoints (summary, reports) return plain dicts.

  6. Vue derives the display

    Raw lists go into refs (allOrders, inventoryItems), and KPIs and chart series are computed properties.

Findings worth knowing

Things I found while tracing the code that aren't obvious from the README.

Frontend calls endpoints that don't exist

api.js defines task CRUD and purchase-order calls, but main.py has no matching routes. GET /api/tasks returns 404 on the running server. App.vue catches the error and logs it.

Reports bypasses the API client

Reports.vue imports axios directly with a hard-coded http://localhost:8001 URL instead of going through api.js, and ignores the global filters.

Time logic is pinned to 2025

QUARTER_MAP and the quarterly report hard-code 2025 months. Month filtering is a substring match on order_date, not a date parse.

Demo-grade security

CORS allows all origins with credentials, there's no auth (the user in useAuth is mocked), and the API binds to 0.0.0.0. That's fine locally, but not something to deploy as is.
